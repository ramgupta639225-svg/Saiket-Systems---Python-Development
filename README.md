# SaiKet Systems – Python Development Internship

This repository contains the six Python projects I completed as part of my Python Development Internship at SaiKet Systems.

The projects helped me practice Python programming, problem-solving, file handling, web scraping, API integration, and data analysis.

## 📌 Internship Overview

- **Company:** SaiKet Systems
- **Domain:** Python Development
- **Program:** Python Development Internship
- **Language:** Python
- **Repository:** SaiKet Systems Python Development Projects

## 📂 Projects

### Task 1: To-Do List Application
A simple command-line application for managing daily tasks.

**Features:**
- Add new tasks
- View all tasks
- Mark tasks as completed
- Track task completion status
- Handle user input

**Concepts Used:** Python basics, lists, dictionaries, loops, and conditional statements.

### Task 2: Guess the Number Game
An interactive number guessing game in which the user tries to guess a randomly generated number.

**Features:**
- Generate a random number
- Accept guesses from the user
- Provide higher or lower hints
- Count the number of attempts
- Display feedback to the user

**Concepts Used:** Random number generation, loops, conditional statements, and user input.

### Task 3: Basic File Handling
A Python program for reading and modifying text files.

**Features:**
- Read text from a file
- Find specific words
- Replace words in the text
- Save modified content
- Handle file-related errors

**Concepts Used:** File handling, string manipulation, and exception handling.

### Task 4: Basic Web Scraper
A web scraping program that extracts relevant information from a website and displays it in a readable format.

**Features:**
- Send HTTP requests
- Parse HTML content
- Extract relevant information
- Display scraped data
- Handle common request errors

**Concepts Used:** Python, Requests, Beautiful Soup, and HTML parsing.

### Task 5: Currency Converter
A Python application for converting an amount from one currency to another using exchange rates.

**Features:**
- Accept the amount and currency codes
- Retrieve exchange rates through an API
- Calculate the converted amount
- Validate user input
- Handle API and conversion errors

**Concepts Used:** API integration, HTTP requests, mathematical operations, and exception handling.

### Task 6: Word Count Tool
A text analysis program that counts words, lines, and characters in a file.

**Features:**
- Read text from a file
- Count words
- Count lines and characters
- Analyze word frequency
- Display the results in a structured format

**Concepts Used:** File handling, string manipulation, dictionaries, and basic data analysis.
